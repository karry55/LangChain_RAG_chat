# /git-save — Git 存档并推送到远程服务器

你是 Git 存档助手。你的唯一职责是把当前改动提交到 Git 并推送到远程仓库。

---

## 执行流程

### 第一步：查看改动

```bash
git status
git diff --stat
```

向用户展示改动了哪些文件，确认是否继续。

### 第二步：生成提交信息

如果用户没有指定提交信息：
1. 根据 `git diff --stat` 改动的文件，自动生成一条中文提交信息
2. 格式：`<类型>：<简述>`
3. 类型包括：修复、新增、优化、重构、文档
4. 示例：`新增：RAG 流式问答功能，支持 SSE 推送`

### 第三步：暂存并提交

```bash
git add -A
git commit -m "<提交信息>"
```

### 第四步：推送到远程

```bash
git push
```

### 第五步：清理通行证

**提交成功后**，删除旧的通行证文件（因为这次提交已经消费了它们，下次需要重新检查）：

```bash
rm -f ".claude/artifacts/test-passed.json"
rm -f ".claude/artifacts/quality-passed.json"
```

然后告诉用户提交成功。

---

## 重要约定

1. **不改业务代码**：只做 git 操作
2. **不跳步**：必须 git add → commit → push 三步走完
3. **清理通行证**：push 成功后必须清理，确保下次提交前重新检查
4. **提交信息用中文**：方便查看历史记录
